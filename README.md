# Field notes

A local kanban board built with Angular. Tasks, columns, and activity stay in this browser.

Feature behavior is inspired by [kargulstudio/kanban](https://github.com/kargulstudio/kanban). That repository has no open-source license. This project does not include its source, assets, name, or sample content.

## Demo

https://angular-kanban-mounir.web.app

## Run

Requires Node.js 22 and npm 11 or newer. npm 10 cannot install this dependency tree.

```bash
npx npm@11 install
npm start
```

Open http://localhost:4200.

| Script | What it does |
| --- | --- |
| `npm start` | Dev server |
| `npm run build` | Production build in `dist/angular-kanban/browser` |
| `npm test` | Unit tests |
